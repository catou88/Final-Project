Linear Regression

Best as a baseline: simple and interpretable, but often too rigid for nonlinear parking patterns.

Decision Tree Logic

A tree learns combinations: event status can matter within each time and location branch. Real boosted models combine many trees with different feature orders and thresholds.

Histogram Gradient Boosting

Strong for structured data because it learns nonlinear patterns and feature interactions.

CatBoost

A good fit when block, neighborhood, weekday, and event labels carry important signal.
